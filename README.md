# Влияние исключений Microsoft Defender на производительность SMB-сервера

## Описание эксперимента

Исследование влияния исключений сетевых папок из сканирования Microsoft Defender на пропускную способность файлового сервера Windows Server 2025.

### Исследовательский вопрос
Как исключение сетевого ресурса из области сканирования Microsoft Defender влияет на измеренную пропускную способность файловых операций?

### Дизайн эксперимента
- **Независимая переменная**: состояние исключения (Baseline / Extension / Path)
- **Зависимая переменная**: медианная пропускная способность (MiB/s)
- **Контролируемые переменные**: объем данных (1000 MiB), тип файлов (.bin), сетевая конфигурация

### Тестовые наборы данных
1. **Small**: 1000 файлов × 1 MiB
2. **Medium**: 100 файлов × 10 MiB  
3. **Large**: 10 файлов × 100 MiB

### Экспериментальные режимы
1. **Baseline**: полное сканирование Microsoft Defender (без исключений)
2. **Extension**: исключение файлов с расширением `.bin`
3. **Path**: исключение пути `C:\LabShare`

### Стенд
- **Сервер**: Windows Server 2025 Standard (VirtualBox, 4 vCPU, 8 GB RAM)
- **Клиент**: Windows 11 Pro (VirtualBox, 4 vCPU, 8 GB RAM)
- **Сеть**: Internal Network LAB (192.168.50.0/24)
- **Протокол**: SMB 3.1.1

### Результаты
Всего выполнено 180 измерений (3 набора × 3 режима × 20 повторений).

Основные результаты:
- **Small**: прирост медианной скорости +28.7% (с 45.85 до 59.00 MiB/s)
- **Medium**: прирост +15.1% (с 139.05 до 160.02 MiB/s)
- **Large**: прирост +2.7% (с 127.18 до 130.67 MiB/s)

## Структура репозитория

- `Create-TestDatasets.ps1` — скрипт для генерации тестовых данных
- `Run-Series.ps1` — скрипт для проведения измерений
- `Series-Collector.ps1` — скрипт для сбора показателей производительности
- `Lab-Experiment-*.csv` - исходные данные всех 180 измерений в формате CSV (9 файлов)
